# 레퍼런스 메모

`guides/`에는 튜토리얼 캡처가 들어 있습니다. 디자인 레퍼런스는 아래에 모읍니다.

URL과 좋았던 점 한 줄이면 충분합니다. 마음에 안 드는 요소도 원하면 덧붙여 주세요.
이미지 파일명은 원본 그대로 써도 됩니다.

## 복사해서 쓰는 빈 양식

```text
- URL 또는 이미지 파일명:
  좋은 점:
```

살펴볼 요소: 전체 분위기, 글자 크기, 여백, 색 조합, 기록 목록, 모바일 화면, 움직임.
모든 항목을 채우거나 사이트 전체를 평가할 필요는 없습니다.

### 03. Son Daven

- URL: https://www.awwwards.com/sites/son-daven
- 실제 사이트: https://sondaven.com/en
- 저장일: 2026-10-18
- 좋은 점: 사용자가 ASCII 느낌의 표현을 새로운 디자인 레퍼런스로 선택했다.
- 화면에서 확인한 요소: 문자·픽셀 같은 거친 타이포그래피, 세로획과 점으로 구성된 그래픽 질감, 절제된 흙빛 계열 색상.
- 적용한 제안: 넓은 여백에 직접 만든 ASCII 입체 블록을 배치하고, 날짜·보조 문구에 monospace를 사용한다. 한글 본문은 읽기 편한 sans-serif로 유지한다.
- [ASCII 시안](../design/ascii-preview.html)과 [기존 시안 비교](../design/compare.html). 원본 코드나 이미지 자산은 가져오지 않았다.
