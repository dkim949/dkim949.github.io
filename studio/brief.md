# 사이트의 기준

## 목적

6개월 뒤 내가 만든 것과 생각의 변화가 조금씩 쌓여 있는 개인 공간. 공개하려면 잘 정리해야 한다는 부담을 낮춘다.

## 방문자와 행동

나의 작업이나 생각에 관심 있는 사람. 첫 화면에서 짧은 기록 하나를 읽고, 관심이 있으면 기존 프로젝트·긴 글·소개로 이어간다. 문의 form 제출이나 정기 구독 전환을 주목적으로 두지 않는다.

## 작성 방식

한 문장이 하나의 기록이다. 제목·요약·썸네일은 필수가 아니다. 날짜가 없는 옛 글에는 임의 날짜를 넣지 않는다. 공개할 메모만 명시적으로 선택하며, 전체 vault나 GitHub 활동을 자동으로 전부 게시하지 않는다.

## 확정된 기반

- Jekyll 3.10, 기존 dkim949.github.io repository와 GitHub Pages.
- 실제 프로젝트 5개, 글 4개, Berlin·Delivery Hero 프로필.
- ASCII 도형, 넓은 여백, 간결한 목록.
- 현재 theme은 [DESIGN.md](../DESIGN.md). 예전 두 도안은 비교용으로 보존.
- 앞으로 작업을 시작할 곳은 이 폴더의 상위 repository 하나다.

## 유튜브 프롬프트에서 채택한 것

- 목적·독자·방문자의 행동과 섹션을 명확히 적는다.
- 레퍼런스마다 참고할 요소를 정한다.
- 구조와 theme을 구분해 수정한다.
- 실제 asset과 참고 screenshot을 구분한다.
- 구현 뒤 직접 실행하고 화면 크기별로 확인한다.

Next.js, gpt-taste 설치, Phosphor Icons, 특정 skill 금지는 영상의 예시 환경에 속한다. 현재 구현의 필요성을 기준으로 판단한다. 브랜드 디자이너의 경력·작품 수·클라이언트 정보는 사용자 프로필이 아니다.
